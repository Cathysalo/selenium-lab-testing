# Selenium Lab Testing

Browser automation and UI testing using Python and Selenium WebDriver.

## Requirements

- Python
- Google Chrome

## Initialization

```bash
python -m venv venv
```

Activate the virtual environment in Git Bash on Windows:

```bash
source venv/Scripts/activate
```

## Dependencies Installation

```bash
python -m pip install selenium
```

## Running Scripts

```bash
python test.py
```

```bash
python find_link.py
```

## Project Files

- `test.py` – Python test script.
- `find_link.py` – Additional browser automation script.
- `.gitignore` – Excludes local files such as the virtual environment.
- `README.md` – Project overview and setup instructions.
